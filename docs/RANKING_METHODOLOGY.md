# Metodologia do Ranking IFB

## Filosofia

O Ranking IFB busca oferecer uma visão objetiva e multidimensional da atuação de cada político, baseada exclusivamente em dados públicos e verificáveis.

**O ranking NÃO é:**
- Uma opinião sobre qualidade do político
- Um julgamento moral
- Uma recomendação de voto
- Uma medida de ideologia

**O ranking É:**
- Uma medida de atividade e transparência
- Uma síntese de dados públicos
- Uma ferramenta de comparação
- Um indicador com metodologia aberta

## Dimensões e Pesos

| Dimensão | Peso | Fonte |
|----------|------|-------|
| Cumprimento de promessas | 25% | Análise IFB + fontes oficiais |
| Presença parlamentar | 15% | Câmara/Senado |
| Atividade legislativa | 15% | Projetos, relatórias, votações |
| Transparência pessoal | 10% | Declarações, respostas, acessibilidade |
| Eficiência de gastos | 15% | Cota parlamentar vs. média |
| Processos judiciais | 10% | Tribunais (apenas condenações reduzem) |
| Prestação de contas | 10% | TSE, campanhas |

## Escala

- **90-100**: Excelente
- **70-89**: Muito bom
- **50-69**: Regular
- **30-49**: Abaixo da média
- **0-29**: Insatisfatório

## Regras

1. Investigação NÃO reduz a nota (presunção de inocência)
2. Apenas condenações transitadas reduzem (dimensão judicial)
3. Falta de dados resulta em "Sem dados suficientes", não em nota baixa
4. Cada componente tem mínimo de dados necessário para calcular
5. A nota é recalculada mensalmente
6. Mudanças de metodologia são versionadas
7. É possível consultar a nota histórica em qualquer versão

## Versionamento

- **v1.0** — Versão inicial (data de vigência será definida no lançamento)
- Mudanças de peso ou fórmula geram nova versão
- Versões anteriores ficam acessíveis para consulta

## Explicabilidade

Cada nota individual mostra:
- Valor do componente
- Fórmula aplicada
- Dados brutos utilizados
- Fonte dos dados
- Data de cálculo
- Versão da metodologia

## Contestação

Qualquer cidadão pode contestar uma nota, desde que apresente:
- Qual componente está incorreto
- Evidência de que os dados estão errados
- Fonte oficial que corrobore a contestação
